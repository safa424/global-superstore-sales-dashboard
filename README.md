# Global Superstore Sales Dashboard

An interactive Power BI dashboard analyzing sales, profit and customer
trends of Global Superstore.

## Dashboard Preview
![Dashboard](images/dashboard.png)

## Objective
To understand overall sales performance and find out which products,
regions and customer segments drive profit (and which cause losses).

## Dataset
- Source: Global Superstore dataset (Kaggle / Tableau sample data)
- Records: ~51,000 rows (change this to your actual count)
- Key columns: Order Date, Region, Category, Sub-Category, Segment,
  Sales, Profit, Quantity, Discount

## Key Metrics (KPIs)
- Total Sales
- Total Profit
- Profit Margin %
- Total Orders
- Quantity Sold

## Visuals Used
- Sales and profit trend by month/year (line chart)
- Sales by region/country (map)
- Sales by category and sub-category (bar chart)
- Sales by customer segment (donut chart)
- Slicers: Year, Region, Category

## Key Insights
- (e.g.) Technology category has the highest sales
- (e.g.) Sales peak in November and December
- (e.g.) High discounts lead to lower profit
- (e.g.) APAC region has the highest sales

## Tools Used
- Power BI Desktop
- DAX
- Power Query

## How to Use
1. Download `dashboardsafa.pbix`
2. Open it in Power BI Desktop
3. Use the slicers to explore the data
